Телесуфлёр

Камера спереди + текст только на экране. В файл уходит чистое видео без суфлёра. Старт — запись, Стоп — сохранить (на iPhone откроется «Поделиться» → «Сохранить видео»). Голос в ухо — через AirPods, чтобы TTS не попал в микрофон.

Чтобы поставить как приложение: Safari → кнопка «Поделиться» → «На экран „Домой“».
