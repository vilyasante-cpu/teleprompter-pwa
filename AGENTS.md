# Телесуфлёр PWA

Публичный мини-приложение: текст поверх фронтальной камеры и голос в наушники.
Исходники для GitHub Pages. Десктопный вариант рядом: `../контент/телесуфлер.html`.

## Файлы

- `index.html` — UI и логика
- `manifest.webmanifest` + `sw.js` — установка на Домой / офлайн
- `icons/` — иконки PWA

## Публикация

Репозиторий: `vilyasante-cpu/teleprompter-pwa` (public), Pages из `main` / root.
URL после деплоя: `https://vilyasante-cpu.github.io/teleprompter-pwa/`

На iPhone: Safari → Поделиться → На экран «Домой».
